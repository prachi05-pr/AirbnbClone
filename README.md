# Airbnb Clone

A full-stack Airbnb Clone built using the MERN stack.

## Features

- User Authentication
- Property Listings
- Booking System
- Image Uploads
- Responsive UI

## Tech Stack

- MongoDB
- Express.js
- React
- Node.js
